# Agent Team Workspace

This folder holds operating docs for developer agents working on this project over time.

## Structure

- `teams.md`: consolidated team model and ownership boundaries.
- `backlog.md`: prioritized cross-team work queue.
- `risk-register.md`: active project risk tracking and mitigation.
- `roles/`: role definitions and responsibilities.

## Usage

1. Pick a role definition from `roles/`.
2. Follow the role's responsibilities, workflow, and deliverables.
3. Keep documents updated as the project grows beyond the first playable version.
