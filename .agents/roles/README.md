# Role Definitions

Each file in this folder defines one agent role.

Current role files:

- `project-manager.md`
- `gameplay-lead.md`
- `platform-lead.md`
- `experience-lead.md`

Each role file should include:

1. Mission
2. Responsibilities
3. Authority and constraints
4. Standard workflow
5. Required artifacts
6. Handoff checklist
7. Coder-lane worktree/branch/PR handoff requirements
