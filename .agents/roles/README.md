# Role Definitions

Each file in this folder defines one agent role.

Current role files:

- `project-manager.md`
- `gameplay-lead.md`
- `platform-lead.md`
- `experience-lead.md`

Each role file should include:

1. Mission
2. Responsibilities
3. Authority and constraints
4. Startup context load requirements
5. Standard workflow
6. Required artifacts
7. Handoff checklist
8. Coder-lane worktree/branch/PR handoff requirements
